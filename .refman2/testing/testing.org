To obtain the latest version of the RefMan project, while keeping the saved citekey data use the following: 
#+begin_src bash
  .refman/reinstall.sh 
#+end_src

To obtain the latest version of the RefMan project run:
#+begin_src bash
  sudo rm -r References 
  git clone git@github.com:and662/RefMan.git References
#+end_src 
NOTE: this will delete any stored data 

build the container: 
#+begin_src bash
    docker build -t refman .
#+end_src



* Testing Papers:

To add a doi to the database:
#+begin_src python
  import add_doi as ADD_DOI
  ADD_DOI.add_doi( '10.1103/PhysRev.106.162' )  
#+end_src

Equivalently, this can be done from the command line:
#+begin_src bash
  .refman2/refman2.sh add-doi 10.1103/PhysRev.106.162  # BCS paper 
  .refman2/refman2.sh add-doi 10.1038/nature26160      # TBG superconductivity paper 
#+end_src

Or if you want more fine grained control: 
#+begin_src python
  import config as CFG
  import database as DB
  import add_doi as ADD_DOI

  config = CFG.Config( config_file = None, verbose_mode = True )
  citekeysDB = DB.database( '../other_citekeys.db', config = config )
  ADD_DOI.add_doi( '10.1038/nature26160', citekeysDB = citekeysDB, config = config )  
#+end_src

This can all be done from the command line: 
#+begin_src bash
  .refman2/refman2.sh add-doi 10.1103/PhysRev.106.162  # BCS paper 
  .refman2/refman2.sh add-doi 10.1038/nature26160      # TBG superconductivity paper 
#+end_src

Use ~./refman.sh add-doi --help~ for a help menu

* Managing Citekeys 

Delete a citekey with:
#+begin_src bash
  .refman2/refman2.sh delete <citekey> 
#+end_src

Rename a citekey with:
#+begin_src bash
  .refman2/refman2.sh rename <old citekey> <new citekey> 
#+end_src
